# 层叠消融

一个离线运行的五关神经网络消融游戏。每关用同一个模拟评估设置比较全开启基线和所选层组合，目标是在准确率约束内减少计算量。

## 运行

在浏览器中直接打开 `index.html`。页面、样式和游戏逻辑均在这一个文件里。也可以在项目目录运行 `python -m http.server 8000`，打开 [http://localhost:8000](http://localhost:8000)。

勾选保留的层，再点击「运行消融实验」。每关通过后可进入下一关，全部五关通过后会进入通关结果页。结果页可以重玩任意关。「重新开始五关」清空本次会话的通关记录和分数。

## 模拟与得分

- 每个任务的模拟准确率等于固定起点、当前开启层的贡献及同时开启的层对贡献之和。层对贡献可以是正数或负数，用来表示协同或重叠。计算量等于固定开销加启用层开销。
- 基线使用完全打开的层组合。变动量按消融配置减基线计算。准确率的差值以百分点（pp）表示，计算量使用模拟单位。所有关卡共用这一比较方法。
- 每次实验按本关的关闭层数、准确率损失上限、计算量上限判定。通过后，规划质量由准确率保留程度与相对计算量节约按 65% 和 35% 加权。每项准确率损失除以该任务容许损失后取平均，改善的指标按零损失计。相对计算量节约是减少的计算量除以基线计算量。
- 每关把所有可通过配置中的最高规划质量定义为 100 分。本次分数按本次规划质量相对最高值换算后四舍五入。总分由五关各自的最高分相加，同一个配置重复运行不会累加分数。
