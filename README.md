# 层叠消融 · Layer Overlay Puzzle

把几何图块平移到棋盘上，拼成给定的目标。相同线段叠偶数次会消失，叠奇数次会保留。

## 运行和操作

直接用浏览器打开 index.html。玩法、关卡和界面在同一个文件内，支持离线运行。页面右上角可切换中英文。

选中图块后，点击或在棋盘上拖动来放置它的锚点。键盘用户可聚焦棋盘，用方向键移动锚点，按回车放置。每个图块使用一次，保持原方向。放好全部图块后，点击「检查图案」。

五关依次得 1、1、2、3、3 分，总分 10 分。完成后可重玩任意一关。重复通过同一关只计一次分。

## 玩法来源

五道题均为网站版原创。叠加规则来自《最强大脑》第五季的「层叠消融」。[江苏卫视节目档案](https://v.jstv.com/a/20180105/1515163436538.shtml) · [节目规则报道](https://www.jiemian.com/article/1875697.html)

## Play in English

Open index.html in a browser and select EN. Slide each piece into position. Coincident line segments toggle on and off with each overlap. Match the target, check the board, and clear all five levels for a total of 10 points.
